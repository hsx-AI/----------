# 水电分厂综合管理平台

基于所提供 8 张浅色效果图，从零实现的 Vue 3 前端业务原型。纯前端，本地演示数据，无后端服务。

## 运行

当前电脑可直接执行项目内的启动脚本：

```bash
./启动前端.sh
```

脚本自动识别当前电脑已有的 Node 与 pnpm，也可按下面的标准方式启动。

推荐 Node.js 22.12+，使用 pnpm（已提供锁文件）：

```bash
pnpm install
pnpm dev
```

默认预览地址 `http://localhost:5173`。若端口被占用，以终端输出为准。手机访问需与电脑位于同一网络，通过终端显示的 Network 地址访问，允许相应端口通过系统防火墙。

```bash
pnpm typecheck
pnpm build
pnpm preview
```

当前 Codex 桌面环境未在 PATH 提供 Node，可使用已安装的运行时：

```bash
export PATH=/home/zns/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:$PATH
/home/zns/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/fallback/pnpm dev
```

## 数据边界

- 页面中的技术通知单、设备、工单、人员、传感器值均为演示数据。
- 演示日期固定为 2026-10-22，页面顶部和新操作记录使用北京时间的实际日期/时间。
- 本地操作保存在 `localStorage` 的 `hydro-platform-v1` 键中，刷新保留，不跨浏览器同步。
- 仅技术通知单的本地执行跟踪可修改；不连接或回写 X5。
- 报修不通知真实维修人员，催办不发送消息，审批与交接复核不具备真实权限验证。
- 所有报表指标有统计口径；考勤趋势图、生产动态、维保计划为固定演示内容。
- 故障照片限 3 张、每张 5MB；前端缩放压缩后保存在浏览器。正式版应改为后端附件服务。
- 二维码编码当前访问地址；从 localhost 生成的二维码不能用于另一台手机访问。正式部署后需用稳定的访问地址生成。
- 不含摄像头扫码识别，使用手机自带扫码工具打开设备链接。
- 原始效果图保留在原目录。页面均由 Vue 组件搭建，没有使用整张截图作为界面。

## 目录

```text
src/
  components/    统一卡片、表格状态、弹窗、图表、设备 SVG 与车间图
  data/seed.ts   演示数据与 TypeScript 类型
  stores/        集中状态、本地持久化、导出和工单工具
  views/         各业务模块
  App.vue        统一应用布局、侧栏、搜索、通知和响应式导航
  main.ts        路由与入口
  style.css      全局设计变量与响应式样式
```

后续替换图形时，可先修改 `MachineArt.vue` 和 `WorkshopMap.vue`，业务数据和状态逻辑可继续复用。技术实施路线见 `IMPLEMENTATION_PLAN.md`。
